# Mandelbrot-julia-set
This was a project I did for my school's maths art competition as I was fascinated by the never-ending repetition of fractals. My final submission can be seen in the repo: julia_set_1 and julia_set_2, a static poster design and a breathing animation. 

I followed tutorials by The Coding Train. Check them out here: https://youtu.be/6z7GQewK-Ks?si=zudNY0f_zodtv45U and https://youtu.be/fAsaSkmbF5s?si=lNsCEHYQekKpQ8Mr.
